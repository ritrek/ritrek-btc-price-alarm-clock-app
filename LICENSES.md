# Bundled alarm recordings

Software in this repository is MIT (see [LICENSE](LICENSE)). That license covers the source code, not the bundled MP3s. This file is the attribution for `assets/sounds/`.

The **compositions** are in the public domain. Each **recording** keeps the license of its source file. Using a recording here does not mean the artist or licensor endorses this app.

Creative Commons BY-SA recordings require: credit for the creator, a link to the source, a link to the license, and a note of any changes. Converting a file to 128 kbps MP3 is a format change, not an adaptation, so ShareAlike does not relicense the app as a whole. William Tell is an excerpt of a U.S. government recording.

Sources were confirmed by matching duration (and, where present, ID3 tags) against Wikimedia Commons and Internet Archive originals.

The in-app copy of this list is Settings → Licenses → Bundled alarm recordings.
